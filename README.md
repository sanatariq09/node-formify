# Formify

A simple Full Stack CRUD application built with **React.js**, **Node.js**, **Express.js**, and **Axios**. It allows users to add, view, edit, and delete user information.

## Features

* Add User
* View Users
* Edit User
* Delete User
* Form Validation
* Responsive UI

## Tech Stack

* React.js
* Node.js
* Express.js
* Axios

## Run Project

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## API

* `GET /api/users`
* `POST /api/users`
* `PUT /api/users/:id`
* `DELETE /api/users/:id`
